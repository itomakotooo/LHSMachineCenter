§1 — STRUCTURAL PROOF (closed-form)
================================================================================

Engine semantics (verified empirically via direct enumeration of all 9³ combos):
  - pay_id 8 (line_3_group "1bar"/"2bar"/"3bar", multiplier 2×) fires on ANY
    bar combo that is NOT line_3_same AND has all non-wild positions in
    {1bar, 2bar, 3bar}. Lands in bucket ge1_lt5.
  - pay_id 8 also fires on (1bar, 2bar, wild) with wild_product=2 → 4×, STILL
    ge1_lt5.
  - pay_id 9 (cherry_count=1, multiplier 1×) fires on ANY single-cherry combo
    (192 combos). Lands in bucket ge1_lt5.
  - pay_id 7 (line_3_same 1bar, 5×) fires on (1bar, 1bar, 1bar). ge5_lt10.
  - pay_id 7 + 1 wild → 10×, ge10_lt20. (1b, 1b, wild) → pay_id 7 (line_3_same
    wins over line_3_group via max).
  - pay_id 5 (line_3_same 2bar, 10×) fires on (2bar, 2bar, 2bar). ge10_lt20.
  - pay_id 71 (cherry_count=2, 5×) fires on 2 cherry + 1 non-cherry. ge5_lt10.
  - pay_id 4 (cherry_count=3, 15×) fires on (cherry, cherry, cherry). ge10_lt20.

Sources mapping (closed-form):
  ge1_lt5  ← cherry-1 (1×) + bar_mixed (2× pure and 4× w/ 1 wild)
  ge5_lt10 ← bar1_pure (5×) + cherry-2 (5×)
  ge10_lt20 ← bar2_pure (10×) + cherry-3 (15×) + 1bar+1bar+wild (10×)

§1.1 hit floor analysis:
  Max non-cherry hit (sum over all bucket caps + uncapped pays):
    bar_mixed P ≤ 14/2 = 7%               (from ge1_lt5 ≤ 14, mult ≥ 2)
    bar1_pure P ≤ 9.5/5 = 1.9%            (from ge5_lt10 ≤ 9.5, mult = 5)
    bar2_pure P ≤ 10/10 = 1%              (from ge10_lt20 ≤ 10, mult = 10)
    1b+1b+wild P ≤ 10/10 = 1% (but coupled to bar2 within g1020 bucket)
    bar3_pure: no cap; small contributes
    bar2+1wild, bar3+1wild, h7 pure, h7+wild, 3 wild: small contributions
  Max non-cherry hit ≈ 7 + 1.9 + 1 + 1 + 0.5 ≈ 11.4% (loose upper bound)
  Hit floor 15% → cherry-1 P ≥ 15 - 11.4 = 3.6%
  cherry-1 RTP ≥ 3.6pp (since mult=1)

§1.2 bar_mixed RTP minimum (AM-GM):
  bar_mixed_P (no 3bar, no wild) = prod_r (p_r+q_r) - prod_r p_r - prod_r q_r
  Constraints:
    bar1_pure_RTP = 5 × prod_r p_r ≥ ge5_lt10_floor (relaxed by cherry-2)
    bar2_pure_RTP = 10 × prod_r q_r ≥ ge10_lt20_floor (relaxed by cherry-3
                                                       and (1b+1b+wild))

  For bar1_pure = 8pp (g510 floor), bar2_pure = 8.5pp (g1020 floor):
    p_prod ≥ 0.016
    q_prod ≥ 0.0085
    Min bar_mixed = p_prod·(1 + (q_prod/p_prod)^(1/3))³ - p_prod - q_prod
                   = 0.016·(1.812)³ - 0.0245
                   = 0.0952 - 0.0245 = 0.0707
    Min bar_mixed_RTP = 0.0707 × 2 × 100 = 14.14pp

  Empirically (10k-grid + 1M random sample):
    Min observed bar_mixed_P = 7.16% (at p1=0.169, p2=0.308, p3=0.308,
                                      q1=0.135, q2=0.238, q3=0.273)
    Min observed bar_mixed_RTP = 14.32pp (slightly above AM-GM bound due to
                                          grid discretization)

§1.3 ge1_lt5 lower bound under hit ≥ 15:
  ge1_lt5 = cherry-1 RTP + bar_mixed RTP ≥ 3.6 + 14.14 = 17.74pp
  User cap: ge1_lt5 ≤ 14.0pp
  GAP = 3.74pp (≥ 27% over cap)

§1.4 cherry pushes ge1_lt5 even HIGHER:
  Adding cherry to fill ge5_lt10 via cherry-2 only RELAXES bar1 floor.
  At cherry sym c, cherry-2_RTP = 15·c²(1-c)·100 pp; bar1 floor relaxes by c2.
  But cherry-1_RTP = 3·c·(1-c)²·100 pp grows much faster than bar1 relaxes.

  cherry_sym=0:    cherry-1=0,   cherry-2=0,    bar_mixed_min=14.07  → g15=14.07
  cherry_sym=1%:   cherry-1=2.9, cherry-2=0.15, bar_mixed_min=13.95  → g15=16.85
  cherry_sym=3%:   cherry-1=8.5, cherry-2=1.31, bar_mixed_min=12.83  → g15=21.30
  cherry_sym=8%:   cherry-1=20.3,cherry-2=8.83, bar_mixed_min=0      → g15=20.30

  Every cherry level gives g15 well over 14pp.

§1.5 Cherry on 1 reel only (R1) — cherry-2/3 stay 0:
  cherry_R1=c → cherry-1 P = c, cherry-2 = cherry-3 = 0
  bar1 floor unrelaxed (8pp), bar2 floor unrelaxed (8.5pp)
  bar_mixed_min = 14.07pp regardless
  ge1_lt5 = c + 14.07
  For hit ≥ 15: need cherry-1 P ≥ 3.6% → c ≥ 3.6%
  ge1_lt5 ≥ 3.6 + 14.07 = 17.67pp > 14

§1.6 Wild substitution:
  Adding dd > 0:
    + Lifts ge10_lt20 via (1b, 1b, wild) at 10×: 3·p²·d ×10·100 pp
    + Lifts ge20_lt50 via (2b, 2b, wild), (1b, wild, wild), (b3, wild, wild)
    + ADDS to bar_mixed via (1b, 2b, wild), (1b, 3b, wild), (2b, 3b, wild)
      at 4× → ge1_lt5 contribution = 6·p·q·d·4·100 pp
    + Doesn't help ge5_lt10 (no wild path lands there)

  Net: dd helps ge10_lt20 but bloats ge1_lt5. dd=0 minimum bar_mixed.

§1.7 3bar contribution:
  Adding r_r > 0:
    + bar3_pure at 20× → ge20_lt50 (uncapped bucket, doesn't help any floor)
    + bar_mixed grows: (p+q+r)³ instead of (p+q)³
    + Doesn't relax any floor

  Optimal r_r = 0.

§1.8 Strip restructure (Lever J):
  analytic_profile depends ONLY on per-reel marginal probabilities.
  Marginal = (sum of weights for symbol s on reel r) / (total weight on reel r).
  Strip layout (stop sequence) doesn't change marginals.
  Strip stop count CAN change marginals only if we add NEW symbol types — but
  the symbol set is locked in spec (cherry, 1bar, 2bar, 3bar, high7, dd,
  topdollar, jackpot, blank).

  Strip restructure preserves the structural conflict.
